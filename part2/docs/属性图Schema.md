# 属性图 Schema

本图谱以「人物」为中心，共 **8 类节点**、**14 种节点-节点关系**、**11 个节点属性**（属性也计入关系种类，合计 25 种，满足参考文档「不少于 10 种」）。

## 一、节点类型

| 节点类型 | Neo4j 标签 | 含义 | 主要属性 |
| --- | --- | --- | --- |
| 人物 | `Person` | 词条主体，图谱的枢纽节点 | 出生日期、性别、星座、血型、身高、体重、外文名、别名、粉丝名称、主要成就、代表作品 |
| 作品 | `Work` | 电影、电视剧、歌曲、专辑、节目等 | 作品类型、年份、饰演角色 |
| 奖项 | `Award` | 各类奖项与其届次 | 获奖年份、届次、获奖结果 |
| 机构 | `Organization` | 学校、经纪公司等组织 | name |
| 地点 | `Place` | 出生地、籍贯等地理实体 | name |
| 国家 | `Country` | 国籍所属国家 | name |
| 民族 | `Ethnicity` | 民族 | name |
| 职业 | `Occupation` | 演员、导演、歌手等职业标签 | name |

| 经纪公司 | 人物 | 机构 | `SIGNED_WITH` | 签约的经纪/唱片公司 |

## 五、设计说明

1. **以人物为中心**：项目一的语料是人物词条，所有关系的 Subject 都是「人物」，天然形成以人物为枢纽的星型结构，查询「某人演过什么/拿过什么奖」只需一跳。
2. **关系与来源对齐**：`参演 / 执导 / 编剧 / 演唱 / 主持 / 获得奖项 / 国籍 / 籍贯 / 毕业院校` 这 9 种能直接映射到 DuIE2.0 的谓词，用 CasRel 训练；`出生地 / 民族 / 职业 / 经纪公司 / 合作` 不在 DuIE 中，用项目一的结构化字段做弱监督补齐。
3. **方向统一**：DuIE 的「主演/导演/编剧/歌手/主持人」是「作品→人物」，训练前统一翻转为「人物→作品」，保证图上所有边都从人物出发。
4. **合作是唯一的人物-人物关系**：由「同句共现 + 合作类触发词」抽取，用它把不同人物连成连通分量，避免图谱碎裂成一堆孤立的星。
